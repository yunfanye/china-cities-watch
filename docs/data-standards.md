# 数据规范

所有城市档案必须遵守本规范，否则不同 agent、不同时间收集的数据无法互相比较。

## 1. 三元组原则

每个定量数据必须同时具备 **数值、年份、来源** 三要素，缺一即视为该项未完成。模板中的"核心指标"表已内置这三列。

## 2. 来源优先级

| 级别 | 类型 | 示例 |
|:----:|------|------|
| P1 | 官方统计 | 该市《国民经济和社会发展统计公报》、市统计局年鉴、政府工作报告、国家统计局 70 城房价指数 |
| P2 | 政府部门 / 行业官方机构 | 住建/教育/卫健/人社部门官网、中国城市轨道交通协会、《中国主要城市通勤监测报告》 |
| P3 | 权威研究机构 / 平台数据 | 贝壳研究院、中指研究院、克而瑞、智联招聘、BOSS 直聘、高德/百度拥堵报告、IT 桔子 |
| P4 | 媒体报道 | 财新、第一财经、21 世纪经济报道等；尽量回溯到其引用的原始来源 |
| P5 | 估算 ⚠️ | 必须标 ⚠️ 并在备注中写明估算方法；能不用就不用 |

同一指标存在多个来源冲突时：取更高级别来源；级别相同取更新的，并在备注中记录分歧。

## 3. 统计口径约定

| 领域 | 默认口径 | 必须注明的情况 |
|------|----------|----------------|
| 人口 | 常住人口 | 使用户籍人口时 |
| 收入 | 全体居民人均可支配收入 | 城镇/农村分项；平均工资须注明"城镇非私营"或"城镇私营" |
| 工资 | 有中位数优先用中位数 | 仅有平均数时注明"平均" |
| 房价 | 二手房成交价 | 使用挂牌价、新房备案价时；注明数据平台 |
| GDP 增速 | 实际增速（不变价） | 使用名义增速时 |
| 通勤 | 单程门到门时间 | 引用口径不同的报告时 |

## 4. 格式约定

- 金额：亿元 / 万元；人口：万人；面积：km²；房价与租金：元/m²、元/月
- 大数字使用千分位或"万/亿"单位，不写长串零
- 日期：`YYYY-MM-DD`；数据年份：`2025`、`2025H1`、`2025Q3` 这类形式
- 来源写法：`机构名《报告/页面名》` + 链接（如有）。链接失效也保留机构与报告名，保证可回溯
- 文件内数据留空时写 `TODO: 未找到（已尝试 XX 渠道）`，不留裸空格

## 5. 状态标记

| 标记 | 含义 |
|:----:|------|
| 🔴 `empty` | 尚未填写 |
| 🟡 `partial` | 部分填写（核心指标表未填完） |
| 🟢 `complete` | 核心指标表填完且有定性解读 |
| ⚠️ `stale` | 已过期：季度类数据 > 6 个月，年度类数据 > 18 个月 |

维度文件头部状态行、`meta.yml`、`cities.yml`、根 README 状态表必须保持一致。

## 6. 历史数据保留

更新指标时**不覆盖旧值**：

1. 将旧值（含年份、来源）移入该文件的"历史数据"表；
2. 在"核心指标"表中填入新值；
3. 在文末"更新记录"表追加一行（日期、维护者、摘要）。

趋势是本仓库最有价值的信息，删除历史等于销毁价值。

## 7. 定性内容写法

- 先事实、后判断："2025 年二手房挂牌量同比 +40%（贝壳），去化压力明显" ✅；"房市不行了" ❌
- 避免空洞形容词（"充满活力""潜力巨大"），改为可验证的表述
- 争议话题呈现两面（如"环境宜居但产业单一"）
- 主观体验类信息（治理、氛围）注明来源类型（本地论坛、社交媒体、实地反馈）
