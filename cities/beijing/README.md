## 一句话定位

全国政治、文化、国际交往和科技创新中心：服务业、数字经济、金融、科研与专业人才密度极高，高质量岗位和公共服务的上限突出；但住房成本、超长通勤、非京籍教育与购车门槛，以及复杂且变化较快的政策，共同抬高长期定居成本。

## 一票否决检查

| 检查项 | 结论 |
|--------|------|
| 气候是否存在难以接受的问题 | **可能**。冬季干冷、春季花粉与风沙、夏季高温强降雨需分别体验 |
| 普通双职工家庭能否负担满足需求的住房 | **核心区压力大**。90m² 按全市挂牌均价约 491.7 万元，相当于双人城镇可支配收入约 25.5 年 ⚠️（推导），且就业/学位板块通常更高 |
| 外来人口落户 / 长期居留是否可行 | **可长期居住，落户竞争强**。积分落户年度规模 6,000 人；工作居住证不是户口 |
| 是否缺少必需教育 / 医疗资源 | **总量不缺，可获得性不均**。入学受区级规则影响，热门医疗资源需求大 |
| 是否无法接受长通勤 | **需重点验证**。模型估计平均单程 47 分钟、29% 超过 60 分钟 |
| 是否依赖私家车 | **是则谨慎**。非京籍申请牌照通常需五年社保和个税，符合资格仍不保证取得指标 |

## 适合谁 / 不适合谁

- **适合**：软件与 AI、科研、金融、咨询、法律、医药、先进制造研发、文化内容、央国企和公共部门人才；重视高密度专业网络、教育文化资源和全国级职业选择的人。
- **谨慎考虑**：需要低成本大面积住房、强确定性学位、短通勤、低压力慢节奏，或必须依赖私家车但尚无牌照的人；非京籍有孩家庭应把完整教育阶段和身份材料一起规划。

## 使用提示

- 平台挂牌和租金是 P3 样本，不是网签成交或住户调查；买房按具体小区核验近 3—6 个月真实成交。
- 北京内部差异远大于全市均值：比较住房时固定就业中心、通勤时长、面积、楼龄和教育条件。
- “12/12 完整”表示十二个维度均已完成一轮研究，不表示每个指标都有高质量公开数字；缺口和降级来源已在正文注明。
- 政策可能继续变化；购房、入学、落户、公积金和车辆申请在办理当日重新核验。
