# 上海城市档案

> 状态：🟢 已完成 ｜ 完整度：12/12 ｜ 主数据年份：2025 ｜ 政策截止：2026-08-31 ｜ 最后更新：2026-09-01 ｜ 维护者：Rome

上海是直辖市，也是全国性经济、金融、贸易、航运和科技创新中心。它的突出优势不是单一指标，而是高密度的高端服务业、先进制造、国际连接、公共交通、高校和顶级医疗共同形成的机会组合；主要代价则是住房负担、跨城尺度通勤、教育与户籍规则复杂，以及快速老龄化。

## 一页结论

| 观察项 | 最新读数 | 判断 | 数据质量 |
|---|---:|---|---|
| GDP | 56,708.71 亿元，实际增长 5.4%（2025） | 体量大、2025 年增长有韧性；服务业占 79.3% | 高：官方公报 P1 |
| 人均 GDP | 22.82 万元（2025，⚠️推算） | 高生产率，但不能直接代表居民可支配收入 | 中高：P1 数据推算 |
| 常住人口 | 2,485.41 万人，较 2024 年 +5.15 万（2025） | 总量近年横盘波动，不宜简单描述为持续净流入 | 高：官方公报 P1 |
| 老龄化 | 65 岁及以上 20.81%（2025-11-01） | 老龄化已深；公共服务与家庭照护压力上升 | 高：1% 人口抽样 P1 |
| 收入 | 全体人均可支配收入 91,987 元（2025） | 居民收入高，但住房与通勤成本显著侵蚀购买力 | 高：官方公报 P1 |
| 工资 | 全口径城镇单位就业人员平均工资 149,208 元/年（2024） | 仅为平均值，不等于典型个人工资或中位数 | 高：人社部门 P1 |
| 住房趋势 | 2026 年 7 月新房同比 +3.0%，二手房同比 -2.0% | 新房与二手房分化；不能用一个“全市均价”概括 | 高：国家统计局指数 P1 |
| 新房金额/面积 | 46,268 元/m²（2025，⚠️全市商品住宅销售额÷面积） | 仅是年度总量均值，不是可比板块成交价 | 中：P1 数据推算 |
| 轨道交通 | 22 条、962 km、532 站（2025，含金山铁路和市域机场线） | 网络强，但外环与跨区通勤仍可能很长 | 高：官方公报 P1 |
| 极端通勤 | 单程 >60 分钟约 18%（数据年 2024） | 就业机会多与职住分离并存 | 中低：研究报告经媒体转述 P4 |
| 医疗 | 每千人执业（助理）医师约 4.09、注册护士约 5.17（2025，⚠️推算） | 顶级与日常医疗资源都强，热门专科体验仍因人而异 | 中高：P1 数据推算 |
| 空气质量 | AQI 优良率 88.5%，PM2.5 26.3 μg/m³（2025） | 颗粒物改善；臭氧仍是需要关注的污染物 | 高：官方公报 P1 |

## 适合谁

- 依赖金融、软件与信息服务、集成电路、生物医药、人工智能、高端制造、国际贸易或专业服务就业密度的人。
- 重视高校、文化活动、国际交通和重症医疗兜底能力，并愿意用更高住房成本换取机会密度的人。
- 能围绕具体就业中心选房，避免把“上海”当作一个单中心城市来规划通勤的人。

## 主要约束

1. **住房统计口径容易误导。** 官方稳定发布的是价格指数、销售额和面积；未找到可长期复现的全市二手房成交均价、分区同质房源价格或挂牌去化周期，因此这些字段没有用平台挂牌价强行补齐。
2. **就业和工资分布公开不足。** 有可靠的全口径平均工资，但没有同口径官方工资中位数、典型职业薪资分布和全市招聘岗位总量；平台样本会因职位、爬取范围和算法变化而漂移。
3. **教育、医疗与住房高度分区。** 城市级总量不能替代具体区、学校、医院和就业中心的可达性分析。
4. **政策变化快。** 住房、落户、绿牌和入学政策应至少每季度复核；本档案的政策有效性核验截止 2026-08-31。

## 数据质量摘要

- **高可信主轴：** 2025 年上海统计公报、2025 年 1% 人口抽样、国家统计局房价指数、上海市级政策文件。
- **中等可信：** 部门专题材料、由官方年度总量推算的比率或均值；均用 ⚠️ 标记公式和局限。
- **低可信或缺失：** 通勤研究经媒体转述；招聘薪酬、职业工资、分区房价租金、学区溢价、三甲医院总数等缺乏统一可复现口径，保留为显式 TODO。
